# Product 1-Pager — Ultra-Simple Commerce MVP

## Summary
A brutally simple e-commerce web app for buying **new electronics** with minimal friction.
The product optimizes for **buyers completing a purchase fast**, while giving sellers the **bare minimum tools** to list items and get paid via **crypto (Ethereum)**.

This MVP is a **learning tool**, not a growth or revenue engine.

---

## Problem

### For buyers
- Buying electronics online is noisy and slow:
  - Too many options
  - Unclear prices, payment flow, or shipping
  - Distracting features that don’t help complete the purchase
- Users want to **find a product and buy it immediately**, without thinking.

### For sellers (secondary)
- Selling online usually requires:
  - Heavy setup
  - Store configuration
  - Operational overhead
- Sellers want a **fast way to list an item and get paid**, nothing more.

---

## Target Users

### Primary user (design driver)
- **Buyers** of new electronics
- Goal: complete a purchase with **≤ 4 clicks**

### Secondary user (enablement only)
- **Individual sellers**
- Any registered user can list products
- Seller experience is **functional, not optimized**

---

## Core Value Proposition
> “Buy new electronics online with almost no friction.”

Not cheaper.
Not more features.
Just **fewer decisions and fewer steps**.

---

## Core Principles (Non-Negotiable)
- Buyer-first
- Fewer steps > more features
- One obvious way to do things
- If it doesn’t help the buyer buy faster, it’s cut

---

## Scope (What the Product DOES)

### Buyer Experience
- Browse a **simple catalog**
- View a product page with:
  - Title
  - Images
  - Description
  - Basic specs
  - Price
  - Shipping info
- Buy a product in **≤ 4 clicks**
- Pay via **crypto (Ethereum)**
- Guest checkout allowed
- See a **minimal order status page**
- Contact seller via **Telegram link-out**

### Seller Experience (Hard-Scoped)
- Register an account
- Define an **Ethereum wallet address**
- Create a product
